# DLavie onboarding tutorial images

Upload the PWA install tutorial images for the DLavie install popup into this folder.

Recommended files:

- `install-welcome.png` — first welcome/tutorial slide image.
- `install-step-share.png` — tutorial image showing the user to tap the browser Share button.
- `install-step-home-screen.png` — tutorial image showing the user to choose Add to Home Screen.

Recommended image specs:

- Format: PNG or WebP.
- Aspect ratio: 4:3.
- Suggested size: 1448 x 1086 or similar.
- Keep file names lowercase and hyphenated.
- Avoid spaces in file names.

Public paths after upload:

- `/onboarding/install-welcome.png`
- `/onboarding/install-step-share.png`
- `/onboarding/install-step-home-screen.png`

Notes:

- These assets are intended for `apps/www` only.
- Do not upload Lenis, Darkroom, or third-party proprietary assets here.
- Use owned/generated DLavie tutorial artwork only.
