# Dlavie v2 Foundation

This document defines the rebuild foundation for the Dlavie ecosystem.

## Principle

Every dependency must power a real feature, route, component, provider, service, or test.

## Products

- Dlavie Website
- Dlavie Commerce
- Dlavie AI
- Dlavie Account
- Dlavie Admin

## Stack

- Next.js App Router
- TypeScript
- Node.js
- Tailwind CSS
- GSAP
- Three.js
- Lenis
- Auth0
- Supabase PostgreSQL
- MongoDB
- Jest
- Playwright
- Vercel
